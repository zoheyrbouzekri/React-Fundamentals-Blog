# React Fundamentals Blog

A simple blog application built with **React** to learn and practice the fundamentals of modern React development.

> **Note:** This project was built by following the **Full Modern React Tutorial** playlist by **Net Ninja** for educational purposes. It helped me gain a solid understanding of React fundamentals and modern development practices.

## Features

* Display a list of blog posts
* View individual blog details
* Create new blog posts
* Delete blog posts
* Client-side routing with React Router
* Data fetching with a custom `useFetch` hook
* Loading and error handling
* Mock REST API using JSON Server

## Tech Stack

* React
* JavaScript (ES6+)
* React Router
* JSON Server
* HTML5
* CSS3

## Getting Started

### Clone the repository

```bash
git clone https://github.com/zoheyrbouzekri/react-fundamentals-blog.git
cd react-fundamentals-blog
```

### Install dependencies

```bash
npm install
```

### Start the JSON Server

```bash
npx json-server --watch data/db.json --port 8000
```

### Start the development server

```bash
npm start
```

Open your browser and navigate to:

```text
http://localhost:3000
```
